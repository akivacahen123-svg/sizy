# סייזי · Sizes

מעלים באנר, כותבים גדלים, ומקבלים אותו מחדש בכל גודל. הטקסט, הלוגו, התמונות והכפתור נחתכים מהבאנר המקורי ומסודרים מחדש, כך שהאותיות נשארות בדיוק כמו במקור.

## איך זה עובד
1. **ה-AI של גוגל (Gemini)** מסתכל על הבאנר ומסמן איפה כל טקסט, לוגו, תמונה וכפתור. זה קורה ב-Worker של Cloudflare, והמפתח נשמר שם בלבד.
2. **המנוע בדפדפן** (`public/engine.js`) חותך כל אלמנט מהפיקסלים המקוריים, מנקה את הרקע ומסדר הכול מחדש לכל גודל. הוא רץ אצל המשתמש, לא בשרת.

## העלאה לאינטרנט (Cloudflare, חינם)
1. נרשמים ב־https://dash.cloudflare.com/sign-up
2. **Workers & Pages** ← **Create** ← **Import a repository**. מחברים את GitHub ובוחרים את המאגר `sizy`. משאירים את ההגדרות כמו שהן ולוחצים **Deploy**.
3. מפתח של גוגל: נכנסים ל־https://aistudio.google.com/apikey ויוצרים מפתח.
4. ב־Cloudflare: **Settings ← Variables and Secrets** ומוסיפים כ־**Secret** את `GEMINI_API_KEY` (המפתח מגוגל). משתמשים באתר לא מתבקשים להדביק שום מפתח.
5. מומלץ מאוד: ליצור את המפתח בלי לחבר כרטיס אשראי או חיוב בגוגל. אז גוגל מגבילה את השימוש בעצמה, ואי אפשר לחרוג מהמכסה החינמית ולשלם.
6. אופציונלי: אתר סגור. מגדירים `APP_PASSWORD` כ־Secret ומשנים `PUBLIC_ACCESS` ל־`"false"`.
7. לוחצים **Deploy** שוב. האתר זמין בכתובת שמסתיימת ב־`workers.dev`.

כל מבקר מוגבל ל־3 ניתוחים בדקה. מי שרוצה אפשר שידביק באתר מפתח Gemini אישי משלו, והוא ישמש אותו במקום המפתח שלך.

מעכשיו כל שינוי שנשמר ב־GitHub עולה לאתר לבד.

## הגדרות (ב־`wrangler.jsonc`)
| משתנה | מה עושה |
|---|---|
| `PUBLIC_ACCESS` | `"true"` פותח את האתר לכולם בלי סיסמה (המפתח שלך משמש את כולם). `"false"` דורש סיסמה |
| `GOOGLE_CLIENT_ID` | אם מוגדר, נכנסים עם חשבון Google |
| `GEMINI_MODEL` | דגם מסוים. ריק: `gemini-flash-latest` עם גיבוי |

## למפתחים
```sh
npm install
cp .dev.vars.example .dev.vars   # למלא סיסמה ומפתח
npm run dev                      # http://localhost:8787
npm test                         # בדיקות שרת ומנוע (גוגל מדומה)
npm run typecheck
```

## כללי העיצוב של סייזי (חלים על כל באנר, לא רק על אחד)

1. **הטקסט נחתך מהמקור** ולא מוקלד מחדש, ונשאר חד: מציירים אותו בגודל המסך האמיתי (כולל מסכים חדים).
2. **כיתוב ממורכז:** כל כיתוב ממורכז מתחת לתמונה שלו, ושורות הכיתוב ממורכזות זו מול זו.
3. **גלריית תמונות** (3 ומעלה, באותו גודל) מסודרת אוטומטית ברשת: בבאנר גבוה בשניים-שניים, כך שהתמונות גדולות.
4. **לוגו שלם:** מילוי חורים פנימיים כדי שהרקע הלבן שבתוכו לא ייחתך.
5. **שוליים:** טקסט צמוד לקצה העליון או התחתון מקבל מרווח.
6. **מסגרת כפתור** נשמרת כקו וקטורי חד (צבע, עובי ופינות מעוגלות מהמקור).
7. **רקע חכם בבאנר צר:** קצוות הרקע (למשל שער אבן) נשארים בגודל טבעי והאמצע מתכווץ.
8. **עריכה:** בחירה מרובה (Ctrl או מסגרת), הזזה, שינוי גודל, מרכוז ועריכת טקסט.
